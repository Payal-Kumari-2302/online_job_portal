# online_job_portal

# 💼 Online Job Portal

A desktop-based **Online Job Portal** developed using **Python, Tkinter, and MySQL**.  
This application provides a simple platform for users to register, log in, explore available jobs, apply for suitable jobs, and track their application status.

The project also includes an **Admin Panel** for managing jobs and monitoring user applications.

---

## ✨ Features

### 👤 User Module

- 📝 User Registration
- 🔐 User Login
- 💼 View Available Jobs
- 📩 Apply for Jobs
- 📋 View My Applications
- 📊 Track Application Status
- 🚪 Logout

### 👨‍💼 Admin Module

- 🔐 Admin Login
- ➕ Manage Job Listings
- 📋 View Job Applications
- 🔄 Update Application Status
- 🚪 Logout
